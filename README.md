## Описание проекта

Оконное приложение на C++ (Windows API, Microsoft Visual Studio 2022) для расчета кредита на жилье.
По введенным процентной ставке, сумме и сроку кредита программа вычисляет ежемесячный платеж,
общую сумму выплат банку и показывает, во сколько раз заемщик переплатит банку.
Архитектура приложения строится по паттерну MVC с активной моделью (вариант 19).

Репозиторий создан на основе учебного репозитория шаблонов [BSUIR-SDLC/SDLC](https://github.com/BSUIR-SDLC/SDLC).
